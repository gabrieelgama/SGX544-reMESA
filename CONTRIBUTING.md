# Contributing

This is an early-stage reverse-engineering project. Research notes, independent tests, documentation corrections, and hardware observations are welcome.

Please include:

- Exact GPU/device and software versions where relevant.
- Whether the result came from static analysis, a vendor driver, or reMESA code.
- Steps to reproduce and relevant logs or hashes.
- A clear distinction between observation and interpretation.

**Do not submit proprietary PowerVR binaries or copied implementation code.** Please get permission before running potentially disruptive tests on someone else's device.
